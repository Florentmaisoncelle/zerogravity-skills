# Zero Gravity AI : packs Claude Code pour gérer une petite entreprise

Chaque pack est un workflow de [zerogravity.builders](https://zerogravity.builders) que Claude Code déroule étape par étape, avec la meilleure compétence à chaque étape. Les packs s'installent un par un, gratuitement. Je les construis et je m'en sers pour mes propres missions de conseil en IA et en automatisation.
