# Le coût par résolution

À lire à l'étape « Quel est le coût ? » de la grille de `SKILL.md`. Aucun prix n'est recopié ici : un prix change, et
une page sans date ne prouve rien. Rouvrir la page de l'éditeur ou du service le jour de la décision, et noter la
date de lecture dans la fiche.

## Formule

**Coût par résolution = (prix de l'outil + jetons ou crédits + temps humain de validation + maintenance) / nombre de
cas traités correctement.**

## Grille à remplir, une colonne par option

| Poste | Existant | Automatisation | Agent |
|---|---|---|---|
| Abonnement ou licence nécessaire | | | |
| Prix à l'usage (crédits, exécutions, jetons) | | | |
| Temps de validation humaine par cas | | | |
| Mise en place (une fois) | | | |
| Maintenance (par mois) | | | |
| Cas traités correctement (pas seulement traités) | | | |
| Coût par résolution | | | |
| Coût actuel du traitement manuel (fourni par la personne) | | | |

Le temps de validation compte : un agent qui exige de tout relire ne coûte pas moins qu'une personne. Le nombre de
cas traités correctement se mesure sur un pilote, avec un taux d'erreur relevé, jamais sur une estimation.

## Unités à ne pas confondre

- **Par résolution** : on ne paie que si le cas est réglé (certains agents intégrés à des outils du marché).
- **Par action** : chaque appel d'outil ou chaque étape se paie, y compris un échec.
- **Par exécution** : un lancement complet d'un workflow, quel que soit le nombre d'étapes (certains services
  d'automatisation).
- **Par crédit** : une action consomme en général un crédit ; les étapes d'IA avancées peuvent en consommer plus.
- **Par licence et par utilisateur** : on paie même sans usage.
- **Par jeton** (agent sur mesure) : se mesure sur un pilote, avec le nombre de jetons par cas et le prix du jour
  chez le fournisseur du modèle. Aucun chiffre à deviner.

## Pièges de comparaison

- Un prix d'exécution n'est pas comparable à un prix d'action ni à un prix de résolution.
- Un prix « à partir de » n'est pas le prix d'un cas.
- Une licence par utilisateur coûte même sans usage ; un prix à la résolution ne coûte qu'à l'usage mais dépend du
  volume. Faire le calcul au volume réel, puis à deux fois le volume.
- Un agent qui échoue coûte quand même, si l'outil facture à l'action.
- La mise en place et la maintenance se comptent, même si elles ne sont pas sur la page de prix.
- Les chiffres d'adoption ou de gain publiés par les éditeurs sont des déclarations de vendeurs. À citer comme telles,
  jamais comme une preuve.

## Quand conclure « rien »

Si le coût par résolution de la meilleure option dépasse le coût actuel du traitement manuel, ou si le volume est trop
faible pour amortir la mise en place, le verdict est « rien », écrit dans la fiche avec le volume qui rouvrirait la
décision.
